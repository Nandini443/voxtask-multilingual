Why VoxTask?

Built for Real Workplace Speech

Standard transcript tools fail when meetings mix languages. VoxTask is custom-tuned for code-switching.

❌ Traditional Meeting Tools
🔴
Fails on Code-Switching: Assumes clean English input, turning Telugu audio into gibberish.
🔴
Manual Note Taking: Deadlines and assigned owners get lost in long unorganized notes.
🔴
Privacy Concerns: Requires sending sensitive company audio to third-party cloud APIs.
✅ VoxTask AI Solution
🟢
Tenglish & Telugu ASR: Hybrid routing with fine-tuned swecha-gonthuka-asr model.
🟢
Automated Task Extraction: Extracts Action, Owner, Deadline, & Urgency in structured JSON.
🟢
Local & Private: Runs Ollama Mistral locally without mandatory cloud dependency.

Capabilities

Features Engineered for Hackathon Victory

🗣️

Code-Switch Detection

Color-coded language badges for English, Telugu, and mixed Tenglish segments with timestamp routing.

👥

Speaker Attribution

Identifies who assigned each task and tags ownership explicitly in the structured checklist.

🚦

Smart Urgency Scoring

Auto-infers priority level (High / Medium / Low) based on deadline urgency words ("urgent", "repu 10 AM").

🔁

BYOK Cloud Fallback

Swappable backend support: run Ollama locally or switch to OpenAI / Anthropic cloud API via sidebar flag.

📊

Meeting Analytics

Visual priority breakdown charts and workload metrics for rapid decision making.

📄

PDF & CSV Report Export

Generates formatted PDF summary reports (ReportLab) and downloadable CSV data for team tools.
